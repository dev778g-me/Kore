Learn how to install and use Kore in a project

## Add to Compose Multiplatform

Kore is distributed via [Maven Central](https://central.sonatype.com/). It is the primary public repository for Java and Kotlin software artifact.

To make sure you have maven central check your `settings.gradle.kts` file.

```kotlin
dependencyResolutionManagement {
    repositories {
        mavenCentral() // <- add this line
    }
}
```

Default:

```kotlin
commonMain.dependencies {
    implementation("io.github.dev778g-me:kore:1.0.0-alpha03")
}
```

or

---

#### Add to Android

```kotlin
implementation("io.github.dev778g-me:kore-android:1.0.0-alpha03")
```

#### Add to Ios-arm64

```kotlin
implementation("io.github.dev778g-me:kore-iosarm64:1.0.0-alpha03")
```

#### Add to Ios-x64

```kotlin
implementation("io.github.dev778g-me:kore-iosx64:1.0.0-alpha03")
```

#### Add to Jvm(desktop)

```kotlin
implementation("io.github.dev778g-me:kore-jvm:1.0.0-alpha03")
```

and then sync the project.
