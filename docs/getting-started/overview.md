# Why Kore ?
<p>
So the question arises why kore ? <br>
Jetpack compose and compose multiplatform let's us create multiplatform apps (for Android, Ios, Desktop, Web) but the default design system is <a href="https://m3.material.io/">Material Design</a> which is not gonna lie is great and beautiful i absolutely love it.But it does not works for all kind of apps and products creating your own design system is quite hard from scratch and not everyone can make good frontends here's why kore comes kore let's you build your own design system with pre-styled components out of the box which you can customize further kore let's you choose colors both dark mode light mode you can customize shapes sizes typography etc .

Kore companion app lets you generate your theme with one click and all components will be styled according to it simple and fast you have to do zero work.

## Key Features
### Fully Themeable 
Creates your own design system tokens manually, or  you can just generate your design system from kore companion app.

### Prestyled
Not everyone is a good at fronted not everyone can build good components from scratch. That's why kore comes with pre-styled components which is beautiful default.  

### Customizable
By default, you can customize the default shapes sizes colors from the theme. If you want to customize further you can customize it via function parameters, almost everything is customizable . if you want more control components have simple apis and each component is self-contained in a single file so you can copy and paste and do whatever you want.
