# RadixColors

[common]\
object [RadixColors](index.md)

Radix UI Color System All color scales in one object both Light and Dark mode.

Each scale has 12 steps with consistent semantic meaning: 1–2  : App / page backgrounds 3–5  : Component backgrounds (default, hover, active) 6–8  : Borders (subtle, normal, strong) 9–10 : Solid fills (buttons, badges, tags) 11–12 : Text & icons (low contrast, high contrast)
